# Bundled fonts

Scoutr bundles these fonts from [Google Fonts](https://fonts.google.com/) under the SIL Open Font License 1.1:

- Space Grotesk — `app/src/main/res/font/space_grotesk.ttf`
- Martian Mono — `app/src/main/res/font/martian_mono.ttf`
- JetBrains Mono — `app/src/main/res/font/jetbrains_mono.ttf`

The full license text is available at https://scripts.sil.org/OFL.

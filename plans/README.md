## Findings considered and rejected

Recorded so they are not re-audited:

- **Claude launch `--name` flag "doesn't exist"** — false; `claude --help`
  shows `-n, --name <name>`. Named claude launches work.
- **Feed teardown race (timers firing after `stop()`)** — the guards at
  `feed.ts:127,140,161` cover it; the only residue is that the CLI never
  calls `feed.stop()` on shutdown, which is moot because the process
  force-exits 2s later.
- **WS upgrade lacks an Origin check** — the token model covers it; the WS
  surface is not browser-reachable in this product.
- **Error responses echo host paths** — authenticated-only surface whose
  subject matter is host paths; not a leak in context.
- **`GET /api/sessions` unbounded read as a security finding** — handled as
  perf/correctness in plan 003 instead.
- **`live-output.ts` 900ms poll, board-detail per-poll cost, LazyColumn
  recomposition** — measured/tuned deliberately; board-detail is the memo
  exemplar the fixes copy.
- **Duplicate `testOptions` block in `app/build.gradle.kts`** — harmless;
  merge opportunistically when that file is next edited.
- **`ConnectionStore.save` nulling ntfy fields** — latent only; its sole
  caller passes values through a guard that prevents the blank write.
- **Robolectric 4.14 pinning tests to SDK 35 (app targets 36)** — real but
  MED-risk for low reward now; revisit when Robolectric ships verified API-36
  support.
- **177 MB `@earendil-works/pi-coding-agent` dependency for one import**
  (`agents/pi/commands.ts`) — a deliberate keep-or-replace decision for the
  maintainer, not an executor task: the SDK is the only guarantee that
  slash-command/settings resolution matches pi's. Decide, then plan.
- **Top-level `allowScripts` key in `bridge/package.json` is a no-op** —
  flagged for the maintainer: either adopt `@lavamoat/allow-scripts` for real
  or delete the key; a one-line decision, not planned.
- **No CI** — `scripts/verify.sh` (plan 008) is the CI entry point when the
  operator provisions a runner; CI setup itself needs operator decisions
  (runner, SDK provisioning) and was deferred deliberately.
- **`$HOME`-is-a-git-repo review-roots hole** — latent on this machine
  (`/home/gdezan/.git` absent); worth a guard when `review.ts` is next
  touched: reject a derived root equal to `homedir()`.
- **ntfy title/`ntfyUrl` egress constraints** — MED-confidence,
  deployment-assumption-dependent; revisit if the ntfy setup ever leaves the
  tailnet.

## Direction options (maintainer decisions, not planned)

Presented during the audit; grounded evidence in the session report:

1. **`codex` agent backend** — cheapest expansion of the core promise; the
   registry + the shipped claude adapter prove the cost. Do plan 003 first
   (catalog scan cost multiplies per backend).
2. **Close the review loop** — start as a steer-to-commit templated prompt
   (zero new privilege), not git-write endpoints.
3. **Multi-host** — the QR payload is already a per-host record;
   `ConnectionStore` is the single-slot bottleneck; depends on architecture
   plan 04 for testability.
4. **Live terminal** (README's v2 path) — most expensive; requires solving
   the WS-close crash class first and a design decision against the
   "escape hatch, not ambient chrome" stance.

# TextMate assets

These assets are redistributed for Scoutr's code viewer.

## Microsoft VS Code grammars and themes

The JavaScript, TypeScript, JSON, Java, Python, Go, Rust, Shell, YAML, SQL, C,
C++, C#, Dart, Swift, Ruby, PHP, Perl, CSS, HTML, XML, INI, Docker grammars,
and the `dark_vs.json` and `dark_plus.json` themes are derived from Microsoft
Visual Studio Code.

Copyright (c) Microsoft Corporation.

## Kotlin grammar

`kotlin.tmLanguage.json` is from vscode-kotlin by Mathias Fröhlich.

Copyright (c) Mathias Fröhlich.

## Markdown grammar

`markdown.tmLanguage.json` is from vscode-markdown-tm-grammar by Microsoft.

Copyright (c) Microsoft Corporation.

MIGRATION — WHAT CHANGES IN THE APP
1. Primary #5B8CFF → #8DF08D, and every onPrimary becomes #04241A, never white.
2. Done stops being green: statusColor(Done) → onSurfaceVariant.
3. DiffPalette.Added #00C8FF → #3FC9E8 so Review never competes with the accent.
4. Status dots become rings: 9dp circle, 2.5dp stroke, no fill.
5. Every pill dies — CircleShape chips and the 22dp composer go to 4/6dp.
6. Bundle Space Grotesk + Martian Mono as font resources; JetBrains Mono stays only if you want a narrower mono in Terminal.
7. Declare surfaceContainer — it was falling through to the M3 default.
HARD RULES
Dark mode only, always. · Green is live, gray is done, red is you. · Mono for machine facts, never for labels. · No shadows, no gradients, no glows, no purple. · Nothing animates unless it is actually happening. · A screen that holds a transcript stays on true black.
